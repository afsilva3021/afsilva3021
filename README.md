## 🚀 Projetos em destaque

### [fastapi-auth-api](https://github.com/afsilva3021/fastapi-auth-api)
API REST de usuários com autenticação JWT (OAuth2 password flow), senhas com bcrypt e arquitetura em camadas (router → service → repository). Migrations com Alembic, testes de integração isolados com pytest + HTTPX e CI no GitHub Actions.

`Python` `FastAPI` `SQLAlchemy 2.0` `Alembic` `PostgreSQL` `pytest` `Docker` `GitHub Actions`

### [FinCore](https://github.com/afsilva3021/FinCore)
Aplicação web financeira e contábil em pt-BR, com páginas renderizadas no servidor e uma API JSON versionada. Migrations aditivas, banco de teste separado e simuladores locais de Pix, boletos e Open Finance.

`Python` `Robyn` `Tortoise ORM` `PostgreSQL` `Bootstrap` `pytest`

### [ConciliadorBancario](https://github.com/afsilva3021/ConciliadorBancario)
Rotina de conciliação bancária integrada ao TOTVS Protheus, desenvolvida em PHP com Composer e estrutura MVC, sem depender das ferramentas da TOTVS (PO-UI).

`PHP` `Composer` `MVC` `TOTVS Protheus` `SQL Server`

### [OpenBiohazard2-Rust](https://github.com/afsilva3021/OpenBiohazard2-Rust)
Port em Rust de uma engine open source do Resident Evil 2, com renderização em SDL2/OpenGL ES 2.0 e leitura dos formatos de arquivo originais do jogo. Projeto pessoal para estudar Rust e programação de baixo nível.

`Rust` `SDL2` `OpenGL ES`
